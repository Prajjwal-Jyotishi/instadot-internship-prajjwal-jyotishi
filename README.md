Day 03 – Banking Management System

Objective:
Develop a Banking Management System using Python functions and exception handling.

Features:
- Deposit money
- Withdraw money
- Check account balance
- View transaction history
- Input validation using exception handling

Concepts Used:
- Functions
- Loops
- Conditional Statements
- Exception Handling
- Lists
- Global Variables

Learning Outcome:
Gained hands-on experience in implementing banking operations and managing transaction records with proper error handling.
