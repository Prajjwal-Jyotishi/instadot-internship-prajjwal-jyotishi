# Day 03 – Banking Management System

## Objective

Develop a Banking Management System using Python functions and exception handling.

## Features Implemented

* Deposit money
* Withdraw money
* Check account balance
* View transaction history
* Input validation using exception handling

## Technologies Used

* Python 3
* Functions
* Loops and Conditional Statements
* Exception Handling
* Lists

## Files Included

### banking_management_system.py

Main application file containing deposit, withdrawal, balance inquiry, and transaction history features.

## Learning Outcomes

* Implementing banking operations using functions
* Managing transaction records with lists
* Error handling for invalid inputs
* Menu-driven program design
